# YP TagForge Plus

[English](README.md) · [MIT](LICENSE)

Подсказки тегов, русские переводы, связанные теги и форматирование промптов в текстовых полях ComfyUI.

## Возможности

- **Danbooru + e621:** теги, алиасы, артисты, персонажи и произведения; локальный русский словарь.
- **Поиск без разделителей:** `onbe` находит `on_bed`, `blueeyes` — `blue_eyes`.
- **Связанные теги:** клик внутри написанного тега или **Ctrl+Shift+Space** открывает варианты с переводами и процентом связи.
- **Префикс артистов:** автоматический `@` при вставке Artist-тегов; можно задать свой префикс или отключить его.
- **Форматирование:** расстановка запятых и пробелов при выходе из поля, очистка лишних разделителей; **Alt+Shift+F** — вручную.
- **Читаемые строки:** чередующийся фон, перенос длинных названий, перевод обычным светлым текстом и книжка со ссылкой на страницу тега.
- **Добавленные теги:** уже присутствующие в промпте варианты показаны тусклее. Учитываются пробелы, подчёркивания, веса и префикс артиста.
- **Размер окна:** регулируемая ширина; высота зависит от количества результатов и места на экране.
- **Совместимость:** классические виджеты, Nodes 2.0 и поля, вынесенные из субграфов.

Поиск работает по локальным CSV. Кнопка **📖** открывает сайт тега; постоянного онлайн-запроса при наборе нет.

## Установка

В каталоге `custom_nodes` твоей установки ComfyUI:

```bash
git clone https://github.com/OsanRey/ComfyUI-YP-TagForge-Plus.git
python -m pip install -r ComfyUI-YP-TagForge-Plus/requirements.txt
```

Используй Python из окружения ComfyUI. Перезапусти ComfyUI, обнови страницу через **Ctrl+F5** и открой **Настройки → YP TagForge Plus**.

## Как пользоваться

Печатай в поле промпта. Стрелки **↑ / ↓** выбирают подсказку, **Enter / Tab** вставляют её. Можно выбирать мышью.

При стандартных настройках выбор подсказки даёт такой результат:

```text
onbe       → on bed,
blueeyes   → blue eyes,
wlop       → @wlop,
```

Клик по уже написанному тегу открывает связанные варианты. Выбор добавляет новый тег после исходного; если тег уже есть, он выделяется в тексте. **📖** открывает страницу тега в новой вкладке.

## Основные настройки

| Настройка | Для чего |
| --- | --- |
| Enable | Включение расширения. |
| Main / extra / translation file | Выбор локальных файлов тегов и перевода. |
| Префикс артистов | По умолчанию `@`; пустое поле отключает префикс. |
| Replace '_' with 'Space' | Замена подчёркиваний пробелами при вставке. |
| Delimiter / Add Space | Разделитель и пробел после вставки. |
| Max Suggestions to Display | Количество подсказок; 0 — все доступные совпадения. |
| Количество связанных тегов | Количество результатов связей. |
| Ширина окна тегов (px) | Ширина от 320 до 1600 px. |
| Форматирование промпта | Включение форматтера. |
| Форматировать при выходе из поля | Автоматическая обработка всего поля. |
| Запятая и пробел в конце строки | Завершающий разделитель. |

Высота определяется количеством тегов; если места не хватает, появляется прокрутка. Изменения настроек применяются сразу.

## Поиск и связи

Фильтр `--Artist` ограничивает поиск артистами; `++` позволяет добавить пользовательский текст перед вставляемым тегом.

Связи ранжируются по совместной встречаемости тегов с помощью коэффициента Жаккара. База связей относится к Danbooru: некоторые артисты, редкие теги и теги только из e621 могут не иметь связей.

Первый запрос создаёт дисковый индекс `data/related.sqlite3`. Он используется при следующих запросах и автоматически перестраивается после изменения исходного CSV.

## Форматирование

```text
Было:  1girl,,solo,  highres
Стало: 1girl, solo, highres,
```

Сохраняются веса, экранированные скобки, LoRA-выражения и wildcard-синтаксис. Границы тегов без разделителей не угадываются: `blue eyes` остаётся одним тегом. Код, числовые векторы и поля предпросмотра пропускаются.

## Совместимость и данные

При включении расширение отключает конкурирующие обработчики подсказок и форматирования через их настройки. Выключение Enable восстанавливает прежние значения в том же браузере.

Расширение работает самостоятельно. Пользовательские CSV тегов размещаются в `tags/`, переводы — в `translate/`. После добавления файлов обнови страницу. Автозагрузки данных при старте нет.

## Обратная связь

Для сообщения об ошибке укажи версии ComfyUI/frontend и короткий пример поиска или вставки.
